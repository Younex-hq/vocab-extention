💡 Anki Import Tip
  1. In Anki, click File > Import and select your downloaded .csv file.
  2. Set Field Separator to Comma.
  3. Map Field 1 → Front (Word), Field 2 → Back (Translation), Field 3 → Definition, Field 5 → Tags.
  4. Click Import to start studying!
